# 🗂️ File Manager Site – Flask-Based File Browser

## 🧠 Description
A **Flask File Manager** web application that allows you to **upload, download, view, and delete files or folders** directly from your browser.  
The project includes a simple **login system**, a **clean bilingual (Hebrew/English)** interface, and detailed file information such as size and last modified date.

---

## 🚀 How to Run

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/PT-CODING/File-Manager-Site.git
cd File-Manager-Site

2️⃣ Install Required Packages
pip install flask werkzeug

3️⃣ Run the Application
python app.py


Then open your browser and navigate to:

http://localhost:5000
